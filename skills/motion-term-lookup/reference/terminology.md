# 前端交互效果术语表 — 262 条 / 20 类

> 按**触发时机**分节，这是本表与同类词库的主要差异：先想「什么时候发生」，再想「动了什么」。
> 每节标题标注来源构成（`原书` = 《Vibe Coding 前端交互效果术语手册》逐字保留；`扩展` = 蒸馏者补充）。
> 原书 68 条的话术列与其原文**逐字一致**，含原文在中文与数字/拉丁字母之间的半角空格，未做规整。
> 扩展条目的话术为规范写法，数值是通用起点，**不是为你的场景算过的**——按自己的距离和元素尺寸重取。

## 怎么用这张表

1. 先按**时机**定位章节（第二至二十一章）；
2. 再按**变化内容**（位移 / 缩放 / 旋转 / 透明度 / 颜色 / 跟随 / 结构展开 / 内容替换）做第二筛；
3. 取「话术」整句，把元素名换成自己的，数值按场景重取；
4. 收尾状态若话术没写，必须自己补（停原位 / 恢复 / 自动消失 / 只播一次）；
5. 数值怎么取、怎么降级，不在本表内 —— 参数与减弱动态配方见 `motion-param-calibrate` 的 `reference/easing-duration.md`；组件级完整配方见 `interaction-brief` 的 `reference/recipes.md`。

## 第二章 页面入场与加载（12 条 · 原书 6 + 扩展 6）

| 逐条入场 | Stagger | 一组元素按顺序错开依次入场 | 列表项依次入场，每一项比前一项晚0.08 秒，从下方淡入上浮。 | 功能列表、图片墙、导航项 |
| 骨架屏 | Skeleton Screen | 加载前显示等布局灰块，带明暗呼吸 | 数据返回前显示与真实布局一致的灰色骨架占位块，带缓慢的明暗呼吸动画，数据到达后替换为真实内容。 | 列表页、信息流、个人中心 |
