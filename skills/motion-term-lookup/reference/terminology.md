## 怎么用这张表

1. 先按**时机**定位章节（第二至十三章 = 12 类）；
2. 再按**变化内容**（位移 / 缩放 / 旋转 / 透明度 / 颜色 / 跟随 / 结构展开 / 内容替换）做第二筛；
3. 取「话术原文」整句，把元素名换成自己的，**数值按自己场景重取**（原值是作者示例值，不是为你的场景算的）；
4. 收尾状态若原话术没写，必须自己补（停原位 / 恢复 / 自动消失 / 只播一次）。
